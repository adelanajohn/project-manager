# Keyboard Shortcuts

Keyboard shortcuts work on Windows/Linux with `Ctrl` and on macOS with `Cmd`, unless specified otherwise.

## Global Shortcuts

These shortcuts work from anywhere in the app.

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + K` | Open command palette / global search |
| `C` | Create new issue (when not focused in a text field) |
| `Esc` | Close current dialog, panel, or modal |
| `Cmd/Ctrl + /` | Toggle keyboard shortcut reference |
| `?` | Show this shortcut reference |
| `G then D` | Go to Dashboard |
| `G then I` | Go to My Issues |
| `G then N` | Go to Notifications |
| `G then S` | Go to Settings |

## Navigation

| Shortcut | Action |
|----------|--------|
| `]` | Collapse/expand the left sidebar |
| `[` | Collapse/expand the right detail panel |
| `Alt + ←` | Navigate back (browser history) |
| `Alt + →` | Navigate forward (browser history) |

## Board Shortcuts

These shortcuts are active when the Kanban board is in focus.

| Shortcut | Action |
|----------|--------|
| `←` `→` | Move focus between columns |
| `↑` `↓` | Move focus between issues in a column |
| `Enter` | Open the focused issue |
| `Spacebar` | Quick-edit the focused issue (inline editing mode) |
| `E` | Edit focused issue title inline |
| `1` | Set focused issue priority to Urgent |
| `2` | Set focused issue priority to High |
| `3` | Set focused issue priority to Medium |
| `4` | Set focused issue priority to Low |
| `A` | Assign focused issue to yourself |
| `Del` or `Backspace` | Delete focused issue (asks for confirmation) |
| `Cmd/Ctrl + Enter` | Move focused issue to next column |
| `Cmd/Ctrl + Shift + Enter` | Move focused issue to previous column |

## Issue Detail

These shortcuts work when an issue detail panel is open.

| Shortcut | Action |
|----------|--------|
| `E` | Start editing the issue title |
| `L` | Open label picker |
| `P` | Open priority picker |
| `A` | Open assignee picker |
| `S` | Open status picker |
| `D` | Open due date picker |
| `M` | Open milestone picker |
| `I` | Open sprint picker |
| `Cmd/Ctrl + Enter` | Submit the open comment or save the edited field |
| `Esc` | Cancel editing / close picker without saving |

## Rich Text Editor (Issue Description / Comments)

Standard Markdown-style shortcuts that work inside the editor.

| Shortcut | Action |
|----------|--------|
| `Cmd/Ctrl + B` | Bold |
| `Cmd/Ctrl + I` | Italic |
| `Cmd/Ctrl + Shift + S` | Strikethrough |
| `Cmd/Ctrl + Shift + C` | Inline code |
| `Cmd/Ctrl + Shift + K` | Insert link |
| `Cmd/Ctrl + Z` | Undo |
| `Cmd/Ctrl + Shift + Z` | Redo |
| `Tab` | Indent list item |
| `Shift + Tab` | Outdent list item |
| `Cmd/Ctrl + Shift + 7` | Numbered list |
| `Cmd/Ctrl + Shift + 8` | Bullet list |
| `Cmd/Ctrl + Shift + 9` | Checklist |
| `Cmd/Ctrl + Shift + B` | Blockquote |
| `Cmd/Ctrl + Alt + C` | Code block |

## Backlog & Issue List

| Shortcut | Action |
|----------|--------|
| `↑` `↓` | Move selection up/down |
| `Enter` | Open selected issue |
| `X` | Toggle selection of focused issue (for bulk actions) |
| `Cmd/Ctrl + A` | Select all visible issues |
| `Esc` | Deselect all |

## Command Palette

When the command palette is open (`Cmd/Ctrl + K`):

| Shortcut | Action |
|----------|--------|
| `↑` `↓` | Navigate results |
| `Enter` | Activate selected result |
| `Esc` | Close palette |
| Start typing | Filter results |
